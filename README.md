# RickVerse

Aplicación para explorar personajes del universo de Rick and Morty construida con **React**, **TypeScript** y **Tailwind CSS**.

**RickVerse** consume una API REST, renderiza un listado de personajes y y comunica de forma explícita los estados de carga y
error, aplica una arquitectura simple para mantener separadas la UI, componentes reutilizables, tipado, manejo de estado
asíncrono y separación entre la interfaz y la capa de API.
